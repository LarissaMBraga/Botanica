# BOTANICA 🌿

A personal plant journal designed to help you organize your plant collection, track growth, and document every stage of your plants' journey.

## About the Project

BOTANICA is a plant management application where users can register their plants, keep track of planting dates and watering schedules, upload photos, and write journal entries to document their plants' progress.

The project combines a clean, nature-inspired interface with practical features to create a simple and enjoyable plant-care experience.

## Features

- **Plant Collection:** Add, view, and manage your plants.
- **Plant Profiles:** Store plant names, species, categories, planting dates, and descriptions.
- **Watering Schedule:** Set watering frequencies for each plant.
- **Photo Upload:** Add and update plant photos.
- **Plant Journal:** Create journal entries with notes and images.
- **Dashboard:** View collection statistics and recently added plants.
- **Data Persistence:** Save plant information using browser local storage.
- **Form Validation:** Validate required fields and provide clear feedback.
- **Responsive Design:** Adapt the interface to different screen sizes.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/LarissaMBraga/botanica.git
```

2. Navigate to the project directory:

```bash
cd botanica
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.
